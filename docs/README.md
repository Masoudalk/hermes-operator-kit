One-command Hermes local computer-operator kit for Windows 11: deterministic GUI controller, computer-use hands and eyes, playbook, skills.

## Install

```powershell
irm https://raw.githubusercontent.com/Masoudalk/hermes-operator-kit/v1.0.0/install.ps1 | iex
```
